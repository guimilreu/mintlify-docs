---
title: "Saldo da carteira"
description: "Consulta o saldo atual de créditos de mensagem da organização."
---

Os créditos de mensagem custeiam o envio via WhatsApp Cloud API. Use este endpoint para verificar o saldo disponível antes de realizar disparos.

## Endpoint

```
GET /v1/message-credits/wallet
```

**Escopo necessário:** `read:message_credits`

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/message-credits/wallet" \
  -H "Authorization: Bearer sk_live_..."
```

## Exemplo de resposta

```json
{
  "data": {
    "balance_cents": 50000,
    "reserved_cents": 1200,
    "available_cents": 48800,
    "currency": "BRL",
    "auto_topup": {
      "enabled": true,
      "thresholdCents": 10000,
      "amountCents": 50000
    },
    "status": "active"
  }
}
```

## Campos da resposta

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `balance_cents` | integer | Saldo total em centavos |
| `reserved_cents` | integer | Valor reservado para envios em andamento |
| `available_cents` | integer | Saldo disponível (`balance - reserved`) |
| `currency` | string | Moeda (`BRL`) |
| `auto_topup` | object | Configuração de recarga automática |
| `status` | string | Status da carteira (`active`, `suspended`) |

<Tip>
Sempre use `available_cents` para verificar se há saldo suficiente — `balance_cents` pode incluir valores já comprometidos com disparos em andamento.
</Tip>
