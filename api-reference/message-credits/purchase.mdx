---
title: "Comprar créditos"
description: "Inicia uma compra de créditos de mensagem via PIX, boleto ou cartão."
---

## Endpoint

```
POST /v1/message-credits/purchase
```

**Escopo necessário:** `write:message_credits`

## Corpo da requisição

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `amountCents` | integer | Sim | Valor da compra em centavos (mín. 500) |
| `billingType` | string | Não | Método de pagamento. Padrão: `PIX` |

### Métodos de pagamento disponíveis

| Valor | Descrição |
|-------|-----------|
| `PIX` | PIX instantâneo (padrão) |
| `BOLETO` | Boleto bancário |
| `CREDIT_CARD` | Cartão de crédito |
| `UNDEFINED` | Qualquer método disponível |

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/message-credits/purchase \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"amountCents": 50000, "billingType": "PIX"}'
```

## Exemplo de resposta (PIX)

```json
{
  "data": {
    "payment_id": "pay_abc123",
    "amount_cents": 50000,
    "pix": {
      "qr_code": "00020126...",
      "copy_paste": "00020126...",
      "expires_at": "2026-06-10T16:30:00.000Z"
    }
  }
}
```

Para pagamentos via PIX, use os dados de `pix` para exibir o QR Code ao usuário. O crédito é liberado automaticamente após a confirmação do pagamento.

<Note>
O saldo é creditado assim que o pagamento é confirmado. Para PIX, isso ocorre em segundos. Para boleto, em até 3 dias úteis.
</Note>
