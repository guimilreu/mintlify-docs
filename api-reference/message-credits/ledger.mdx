## Endpoint

```
GET /v1/message-credits/ledger
```

**Escopo necessário:** `read:message_credits`

<Note>
Este endpoint usa paginação por **página** (não cursor como os demais). Use os parâmetros `page` e `limit`.
</Note>

## Parâmetros de query

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `page` | integer | Página. Padrão: `1` |
| `limit` | integer | Itens por página. Padrão: `30`. Máximo: `100` |

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/message-credits/ledger?page=1&limit=30" \
  -H "Authorization: Bearer sk_live_..."
```

## Exemplo de resposta

```json
{
  "data": {
    "items": [
      {
        "id": "664o0p1q2r3s4t5u6v7w8x9y",
        "type": "debit",
        "amount_cents": -120,
        "balance_after_cents": 48880,
        "description": "Envio WhatsApp Cloud — template boas_vindas",
        "created_at": "2026-06-10T15:30:00.000Z"
      }
    ],
    "pagination": { "page": 1, "limit": 30, "total": 412, "pages": 14 }
  }
}
```

## Campos do item

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID do lançamento |
| `type` | string | `debit` (saída) ou `credit` (entrada) |
| `amount_cents` | integer | Valor em centavos (negativo = débito) |
| `balance_after_cents` | integer | Saldo após o lançamento |
| `description` | string | Descrição da operação |
| `created_at` | string | Data/hora do lançamento (ISO 8601) |
