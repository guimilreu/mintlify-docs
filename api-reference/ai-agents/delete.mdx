---
title: "Excluir agente de IA"
description: "Remove permanentemente um agente de IA."
---

## Endpoint

```
DELETE /v1/ai-agents/:id
```

**Escopo necessário:** `write:ai_agents`

<Warning>
A exclusão é **permanente**. As execuções (runs) já registradas continuam no histórico e seguem consultáveis por `agent_id`.
</Warning>

<Note>
Um agente `active` **não** pode ser excluído — a resposta é `422 INVALID_STATUS`. [Pause](/api-reference/ai-agents/pause) antes.
</Note>

## Exemplo de requisição

```bash
curl -X DELETE https://api.socialsell.ai/v1/ai-agents/66445c483fa9572a0b2496cb \
  -H "Authorization: Bearer sk_live_..."
```

## Resposta

Retorna `HTTP 204 No Content` em caso de sucesso.

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Agente não encontrado |
| `INVALID_STATUS` | `422` | O agente está ativo. Pause antes de excluir |
