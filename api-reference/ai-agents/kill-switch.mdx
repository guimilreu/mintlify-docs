---
title: "Kill Switch global"
description: "Pausa ou restaura todos os agentes de IA da organização de uma vez."
---

## Endpoint

```
POST /v1/ai-agents/kill-switch
```

**Escopo necessário:** `write:ai_agents`

O kill switch é um controle de emergência que pausa **todos** os agentes ativos da organização simultaneamente. Ao desativar, os agentes são restaurados ao estado `active` anterior.

## Corpo da requisição

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `enabled` | boolean | Sim | `true` pausa todos os agentes; `false` restaura |
| `reason` | string | Não | Motivo (registrado para auditoria) |

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/ai-agents/kill-switch \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"enabled": true, "reason": "Manutenção emergencial"}'
```

## Exemplo de resposta

```json
{
  "data": {
    "kill_switch": {
      "enabled": true,
      "enabled_at": "2026-06-10T16:00:00.000Z",
      "reason": "Manutenção emergencial"
    }
  }
}
```

<Warning>
Use com cautela. Ao ativar o kill switch, **nenhum agente responderá** a conversas novas até que seja desativado.
</Warning>

## Campos da resposta

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `kill_switch.enabled` | boolean | Se o kill switch está ativo |
| `kill_switch.enabled_at` | string \| null | Quando foi acionado |
| `kill_switch.reason` | string \| null | Motivo registrado |

## Como a restauração funciona

Ao ativar, a plataforma guarda quais agentes estavam `active` e pausa todos. Ao desativar, **só esses** voltam a `active` — um agente que já estava pausado antes continua pausado, e um criado no intervalo não é ativado sozinho.

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `VALIDATION_ERROR` | `400` | `enabled` ausente, ou `reason` acima de 500 caracteres |
| `NOT_FOUND` | `404` | Organização não encontrada |
