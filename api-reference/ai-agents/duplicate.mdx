---
title: "Duplicar agente"
description: "Cria uma cópia de um agente existente, em rascunho."
---

## Endpoint

```
POST /v1/ai-agents/:id/duplicate
```

**Escopo necessário:** `write:ai_agents`

Copia toda a configuração — `scope`, `triggers`, `behavior`, `aiConfig`, `guardrails`, `toolsAllowed` e `limits`. A cópia nasce com:

- nome do original acrescido de **“(cópia)”**
- `status: draft`
- estatísticas zeradas

É o caminho recomendado para testar mudanças sem tocar no agente que está atendendo.

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/ai-agents/66445c483fa9572a0b2496cb/duplicate \
  -H "Authorization: Bearer sk_live_..."
```

## Resposta

Retorna `HTTP 201` com o novo agente em `status: draft`.

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Agente não encontrado |
| `MISSING_AUTHOR` | `422` | A API Key não tem usuário criador associado |
