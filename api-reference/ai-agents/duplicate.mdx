---
title: "Duplicar agente"
description: "Cria uma cópia de um agente existente em status de rascunho."
---

## Endpoint

```
POST /v1/ai-agents/:id/duplicate
```

**Escopo necessário:** `write:ai_agents`

Cria uma cópia completa do agente (configuração, triggers, behavior) com status `draft`. Útil para criar variações ou testar mudanças sem afetar o agente em produção.

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/ai-agents/664p1q2r3s4t5u6v7w8x9y0z/duplicate \
  -H "Authorization: Bearer sk_live_..."
```

## Resposta

Retorna `HTTP 201` com o novo agente em `status: draft`.
