---
title: "Buscar execução"
description: "Retorna os dados completos de uma execução de agente pelo ID."
---

## Endpoint

```
GET /v1/ai-agents/runs/:id
```

**Escopo necessário:** `read:ai_agents`

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/ai-agents/runs/664831860ee9b03de1982629" \
  -H "Authorization: Bearer sk_live_..."
```

Retorna o objeto run completo, incluindo `messages_sent`, `handoff`, `usage`, `evaluation` e `duration_ms`.

O objeto devolvido é o mesmo descrito em [Listar execuções](/api-reference/ai-agents/runs-list).

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Execução não encontrada |
