---
title: "Buscar agente de IA"
description: "Retorna os dados completos de um agente de IA pelo ID."
---

## Endpoint

```
GET /v1/ai-agents/:id
```

**Escopo necessário:** `read:ai_agents`

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/ai-agents/66445c483fa9572a0b2496cb" \
  -H "Authorization: Bearer sk_live_..."
```

Retorna o objeto agente completo, incluindo toda a configuração de `scope`, `triggers`, `behavior`, `humanization`, `guardrails`, `tools_allowed`, `limits` e `ai_config`.

<Tip>
Use este endpoint como referência para montar o corpo ao criar ou atualizar agentes — a estrutura dos objetos aninhados é idêntica.
</Tip>

O formato é o mesmo descrito em [Listar agentes](/api-reference/ai-agents/list).

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Agente não encontrado |
