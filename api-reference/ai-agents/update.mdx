---
title: "Atualizar agente de IA"
description: "Atualiza a configuração de um agente de IA existente."
---

## Endpoint

```
PATCH /v1/ai-agents/:id
```

Também disponível como `PUT /v1/ai-agents/:id` — mesmo handler, mantido por compatibilidade.

**Escopo necessário:** `write:ai_agents`

## Semântica da atualização

O corpo aceita os mesmos campos de [Criar agente](/api-reference/ai-agents/create), todos opcionais, em **snake_case**.

| Nível | Comportamento |
|-------|---------------|
| Campos de primeiro nível | Só os enviados mudam. Os demais permanecem |
| `sales_method_id` | Ausente não mexe no método; `null` remove a atribuição do agente |
| Objetos aninhados (`scope`, `behavior`, `ai_config`, `limits`…) | **Substituídos por inteiro**, não mesclados |

<Warning>
  Enviar `ai_config: { "persona": { "name": "Alice" } }` **descarta** todo o resto do `ai_config` —
  instruções, memórias, regras de ação. Leia o agente com
  [`GET /v1/ai-agents/:id`](/api-reference/ai-agents/get), altere o objeto completo e devolva inteiro.
</Warning>

## Exemplo — alterar nome e prioridade

```bash
curl -X PATCH https://api.socialsell.ai/v1/ai-agents/66445c483fa9572a0b2496cb \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"name": "Qualificador de Leads v2", "priority": 20}'
```

## Resposta

Retorna `HTTP 200` com o agente atualizado.

<Warning>
Atualizar um agente `active` vale **imediatamente** para as próximas execuções. Para testar mudanças sem impacto em produção, pause o agente antes, ou trabalhe numa [cópia](/api-reference/ai-agents/duplicate).
</Warning>

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `VALIDATION_ERROR` | `400` | Corpo inválido. `details[]` aponta o campo em snake_case |
| `FORBIDDEN` | `403` | O usuário da API Key não pode gerenciar agentes, ou um ID enviado não é da organização |
| `MISSING_AUTHOR` | `422` | A API Key não tem usuário criador associado |
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Agente não encontrado |
