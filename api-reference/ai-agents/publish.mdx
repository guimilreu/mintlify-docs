---
title: "Publicar agente"
description: "Ativa um agente de IA em rascunho, colocando-o em produção."
---

## Endpoint

```
POST /v1/ai-agents/:id/publish
```

**Escopo necessário:** `write:ai_agents`

Transição de status: `draft` → `active`

Após publicado, o agente começa a responder às conversas conforme seus triggers configurados.

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/ai-agents/664p1q2r3s4t5u6v7w8x9y0z/publish \
  -H "Authorization: Bearer sk_live_..."
```

## Resposta

Retorna `HTTP 200` com o agente no status `active`.
