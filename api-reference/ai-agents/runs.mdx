---
title: "Execuções e estatísticas"
description: "Liste execuções (runs) de agentes, registre feedback e consulte estatísticas."
---

Cada vez que um agente atua em uma conversa, gera um **run**. Estes endpoints permitem auditar execuções, dar feedback e ver métricas.

**Escopos:** `read:ai_agents` (leitura), `write:ai_agents` (feedback).

## Listar execuções

```
GET /v1/ai-agents/runs
```

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `agent_id` | string | Filtra por agente |
| `conversation_id` | string | Filtra por conversa |
| `status` | string | Filtra por status do run |
| `started_after` | string | ISO 8601 |
| `limit` | integer | Padrão `25`, máx `100` |
| `cursor` | string | Paginação por cursor |

```bash
curl "https://api.socialsell.ai/v1/ai-agents/runs?agent_id=664p1q2r3s4t5u6v7w8x9y0z&limit=10" \
  -H "Authorization: Bearer sk_live_..."
```

### Objeto run

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID do run |
| `agent` | object | Agente `{id, name, type}` |
| `conversation_id` | string\|null | Conversa onde atuou |
| `trigger_event` | string\|null | Evento disparador |
| `status` | string | Status do run |
| `skip_reason` | string\|null | Motivo de pulo (se não atuou) |
| `error_message` | string\|null | Erro, se houver |
| `messages_sent` | array | Mensagens enviadas pelo agente |
| `handoff` | object\|null | Detalhes de transferência para humano |
| `usage` | object\|null | Tokens e custo |
| `evaluation` | object\|null | Avaliação automática e feedback humano |
| `duration_ms` | integer\|null | Duração da execução |
| `started_at` / `completed_at` | string\|null | Timestamps |

## Buscar execução

```
GET /v1/ai-agents/runs/:id
```

## Registrar feedback

```
POST /v1/ai-agents/runs/:id/feedback
```

**Escopo:** `write:ai_agents`

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `rating` | number | Sim | Avaliação da execução |
| `issues` | string[] | Não | Problemas: `wrong_info`, `missed_intent`, `premature_handoff`, `late_handoff`, `tone_issue`, `other` |
| `comment` | string | Não | Comentário livre |

```bash
curl -X POST https://api.socialsell.ai/v1/ai-agents/runs/664q2r3s4t5u6v7w8x9y0z1a/feedback \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"rating": 2, "issues": ["premature_handoff"], "comment": "Transferiu cedo demais."}'
```

## Estatísticas

```
GET /v1/ai-agents/stats
```

**Escopo:** `read:ai_agents`

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `agentId` | string | Filtra por agente específico |
| `startDate` | string | ISO 8601 |
| `endDate` | string | ISO 8601 |
| `periodDays` | integer | Janela em dias (padrão `30`) |

```bash
curl "https://api.socialsell.ai/v1/ai-agents/stats?periodDays=30" \
  -H "Authorization: Bearer sk_live_..."
```

Retorna métricas agregadas de execuções, handoffs, tokens e custo no período.
