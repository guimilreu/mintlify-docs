---
title: "Registrar feedback"
description: "Envia avaliação humana sobre a qualidade de uma execução de agente."
---

## Endpoint

```
POST /v1/ai-agents/runs/:id/feedback
```

**Escopo necessário:** `write:ai_agents`

O feedback humano é usado para monitorar a qualidade dos agentes e identificar padrões de erro. Pode ser integrado a fluxos de revisão internos.

## Corpo da requisição

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `rating` | number | Sim | Avaliação de `1` a `5`. Fora da faixa devolve `400` |
| `issues` | string[] | Não | Problemas identificados |
| `comment` | string | Não | Comentário livre |

### Tipos de issue disponíveis

| Valor | Descrição |
|-------|-----------|
| `wrong_info` | Informação incorreta fornecida |
| `missed_intent` | Não entendeu a intenção do cliente |
| `premature_handoff` | Transferiu para humano cedo demais |
| `late_handoff` | Demorou para transferir quando deveria |
| `tone_issue` | Tom inadequado na resposta |
| `other` | Outro problema |

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/ai-agents/runs/664831860ee9b03de1982629/feedback \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"rating": 2, "issues": ["premature_handoff"], "comment": "Transferiu cedo demais, poderia ter resolvido."}'
```

## Resposta

Retorna `HTTP 200` com o feedback registrado.

O corpo devolvido é a execução completa, já com `evaluation.humanFeedback` preenchido — mesmo objeto de [Listar execuções](/api-reference/ai-agents/runs-list).

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `VALIDATION_ERROR` | `400` | `rating` fora de `1`–`5`, `issue` fora da lista, ou `comment` acima de 1000 caracteres |
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Execução não encontrada |
