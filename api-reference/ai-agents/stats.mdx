description: "Métricas agregadas de execuções, transferências, tokens e custo por período."

## Endpoint

```
GET /v1/ai-agents/stats
```

**Escopo necessário:** `read:ai_agents`

Consolida as execuções de todos os agentes da organização — ou de um agente específico — dentro de uma janela de tempo.

## Parâmetros de query

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `agentId` | string | Restringe a um agente. Omitido, agrega todos |
| `periodDays` | integer | Janela em dias contados a partir de agora. De `1` a `365`. Padrão: `30` |
| `startDate` | string | ISO 8601 — início do período |
| `endDate` | string | ISO 8601 — fim do período |

<Note>
  `startDate` e `endDate` só valem **juntos**: informando os dois, `periodDays` é ignorado e a resposta
  traz `kpi_period_days: null`. Informando apenas um deles, a janela dos KPIs continua sendo
  `periodDays`.
</Note>

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/ai-agents/stats?periodDays=30" \
  -H "Authorization: Bearer sk_live_..."
```

## Campos da resposta

### Execuções

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `total_runs` | integer | Execuções no período |
| `completed_runs` | integer | Execuções concluídas |
| `failed_runs` | integer | Execuções que falharam |
| `handoff_runs` | integer | Execuções que terminaram transferindo para uma pessoa |
| `avg_duration_ms` | number | Duração média de uma execução |
| `avg_messages_per_run` | number | Mensagens enviadas por execução, em média |

### Taxas

| Campo | Tipo | Como é calculada |
|-------|------|------------------|
| `resolution_rate` | number | `(completed_runs − handoff_runs) / total_runs`, em % com uma casa. O que a IA resolveu sozinha |
| `handoff_rate` | number | `handoff_runs / total_runs`, em % |
| `error_rate` | number | `failed_runs / total_runs`, em % |

### Custo

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `total_tokens` | integer | Tokens consumidos no período |
| `total_cost_usd` | number | Custo estimado em dólares |
| `avg_cost_per_conversation` | number | `total_cost_usd / total_runs` |

### Alcance

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `active_agents_count` | integer | Agentes em `active` **agora** — não é filtrado pelo período |
| `messages_sent_by_ai` | integer | Mensagens enviadas por agentes no período |
| `conversations_where_ai_responded` | integer | Conversas distintas em que a IA respondeu |
| `conversations_with_ai_active_now` | integer | Conversas com agente ativo **neste momento** — não é filtrado pelo período |
| `conversations_passed_to_team` | integer | Conversas distintas transferidas para uma pessoa |

### Janela

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `kpi_period_days` | integer \| null | Janela usada. `null` quando você informou `startDate` **e** `endDate` |
| `kpi_from` | string | Início efetivo do período, ISO 8601 |
| `kpi_to` | string | Fim efetivo do período, ISO 8601 |

<Note>
  `total_runs` e derivados respeitam `startDate`/`endDate` quando informados. Já `active_agents_count` e
  `conversations_with_ai_active_now` são fotografias do **agora** — use-os para monitoramento, não para
  comparar períodos.
</Note>

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `VALIDATION_ERROR` | `400` | Parâmetro fora do formato — por exemplo `periodDays` acima de `365` |
