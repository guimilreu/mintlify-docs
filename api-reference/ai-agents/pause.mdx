---
title: "Pausar agente"
description: "Pausa um agente de IA, interrompendo novas execuções."
---

## Endpoint

```
POST /v1/ai-agents/:id/pause
```

**Escopo necessário:** `write:ai_agents`

Transição: `active` → `paused`. O agente para de reagir a novos eventos; execuções já em andamento terminam normalmente.

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/ai-agents/66445c483fa9572a0b2496cb/pause \
  -H "Authorization: Bearer sk_live_..."
```

## Resposta

Retorna `HTTP 200` com o agente em `status: paused`.

<Tip>
Para pausar **todos** os agentes da organização de uma vez, use o [Kill Switch](/api-reference/ai-agents/kill-switch).
</Tip>

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Agente não encontrado |
