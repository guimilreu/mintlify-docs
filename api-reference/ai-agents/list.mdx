---
title: "Listar agentes de IA"
description: "Retorna os agentes de IA da organização."
---

## Endpoint

```
GET /v1/ai-agents
```

**Escopo necessário:** `read:ai_agents` — disponível quando o plano inclui o módulo **Agentes de IA** (Growth ou superior)

Ordenados por `priority` decrescente e, no empate, do mais recente para o mais antigo.

## Parâmetros de query

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `type` | string | `sales` ou `support` |
| `status` | string | `draft`, `active` ou `paused` |
| `limit` | integer | Itens por página. Padrão: `25`. Máximo: `100` |
| `cursor` | string | Token de paginação |

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/ai-agents?status=active" \
  -H "Authorization: Bearer sk_live_..."
```

## Objeto agente

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID do agente |
| `name` | string | Nome |
| `description` | string \| null | Descrição |
| `type` | string | `sales` ou `support` |
| `status` | string | `draft`, `active` ou `paused` |
| `priority` | integer | `0` a `100`. **Maior = mais prioritário** quando dois agentes cobrem a mesma conversa |
| `scope` | object \| null | Canais, tipos de conversa e restrições de número |
| `triggers` | array | Eventos que acionam o agente |
| `behavior` | object \| null | O trabalho do agente: `strategy` (só `support`; `null` em `sales`), `triage`, `sales` (só `sales`; `null` em `support`), `follow_up`, `meetings` e fila. Campos em [Criar agente](/api-reference/ai-agents/create) |
| `sales_method` | object \| null | Método atribuído ao agente: `{id, name, stages: [{key, name}]}`. `null` sem atribuição própria (o agente pode herdar o da equipe ou da organização) |
| `humanization` | object \| null | `{pace, send_typing_indicator}` |
| `guardrails` | object \| null | `{restrictions, required_disclosures}` |
| `tools_allowed` | object | As 13 ferramentas, uma chave booleana cada, já com o padrão por tipo aplicado |
| `materials` | object | `{media_folder_ids, media_ids}` |
| `limits` | object \| null | `{max_messages_per_conversation_per_day, daily_credits_budget}` |
| `ai_config` | object \| null | Persona, instruções, memórias, regras de ação e `audio_replies` |
| `stats` | object \| null | Acumulados do agente. Ver abaixo |
| `created_at` | string | Criação |
| `updated_at` | string | Última atualização |

<Note>
  Desde 13/10/2026 os objetos aninhados também voltam em snake_case, no mesmo formato aceito na escrita.
  Ver [Criar agente](/api-reference/ai-agents/create).
</Note>

### Objeto `stats`

Acumulado desde sempre, não por período. Para métricas com janela de tempo e taxas calculadas, use [Estatísticas](/api-reference/ai-agents/stats).

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `total_runs` | integer | Execuções do agente |
| `completed_runs` | integer | Execuções concluídas |
| `failed_runs` | integer | Execuções que falharam |
| `avg_response_time_ms` | number | Tempo médio de resposta |
| `avg_messages_per_run` | number | Mensagens por execução, em média |
| `total_tokens_used` | integer | Tokens consumidos |
| `total_cost_usd` | number | Custo acumulado em dólares |
| `last_run_at` | string \| null | Última execução |

## Erros

Além dos erros comuns a toda a API — [autenticação](/api-reference/authentication), [escopo](/api-reference/scopes) e [limite de requisições](/api-reference/rate-limits) — esta rota pode responder:

| Código | Status | Descrição |
|--------|--------|-----------|
| `INTERNAL_ERROR` | `500` | Falha interna ao processar a requisição |
