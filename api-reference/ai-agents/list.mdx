---
title: "Listar agentes de IA"
description: "Retorna os agentes de IA da organização."
---

## Endpoint

```
GET /v1/ai-agents
```

**Escopo necessário:** `read:ai_agents` — disponível no plano **Growth ou superior**

Ordenados por `priority` decrescente e, no empate, do mais recente para o mais antigo.

## Parâmetros de query

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `type` | string | `sales` ou `support` |
| `status` | string | `draft`, `active` ou `paused` |
| `limit` | integer | Itens por página. Padrão: `25`. Máximo: `100` |
| `cursor` | string | Token de paginação |

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/ai-agents?status=active" \
  -H "Authorization: Bearer sk_live_..."
```

## Objeto agente

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID do agente |
| `name` | string | Nome |
| `description` | string \| null | Descrição |
| `type` | string | `sales` ou `support` |
| `status` | string | `draft`, `active` ou `paused` |
| `priority` | integer | `0` a `100`. **Maior = mais prioritário** quando dois agentes cobrem a mesma conversa |
| `scope` | object \| null | Canais, tipos de conversa e restrições de número |
| `triggers` | array | Eventos que acionam o agente |
| `behavior` | object \| null | Estratégia, transferência e fila |
| `humanization` | object \| null | `{pace, sendTypingIndicator}` |
| `guardrails` | object \| null | `{restrictions, requiredDisclosures}` |
| `tools_allowed` | object \| null | Ferramentas liberadas, uma chave booleana por ferramenta |
| `limits` | object \| null | `{maxMessagesPerConversationPerDay, dailyCreditsBudget}` |
| `ai_config` | object \| null | Persona, instruções, memórias e regras de ação |
| `stats` | object \| null | Acumulados do agente. Ver abaixo |
| `created_at` | string | Criação |
| `updated_at` | string | Última atualização |

<Note>
  Os objetos aninhados voltam em **camelCase por dentro** (`maxMessagesPerConversationPerDay`,
  `sendTypingIndicator`), mesmo com as chaves de primeiro nível em snake_case. É o mesmo formato aceito
  na escrita — ver [Criar agente](/api-reference/ai-agents/create).
</Note>

### Objeto `stats`

Acumulado desde sempre, não por período. Para métricas com janela de tempo e taxas calculadas, use [Estatísticas](/api-reference/ai-agents/stats).

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `totalRuns` | integer | Execuções do agente |
| `completedRuns` | integer | Execuções concluídas |
| `failedRuns` | integer | Execuções que falharam |
| `avgResponseTimeMs` | number | Tempo médio de resposta |
| `avgMessagesPerRun` | number | Mensagens por execução, em média |
| `totalTokensUsed` | integer | Tokens consumidos |
| `totalCostUsd` | number | Custo acumulado em dólares |
| `lastRunAt` | string \| null | Última execução |

## Erros

Além dos erros comuns a toda a API — [autenticação](/api-reference/authentication), [escopo](/api-reference/scopes) e [limite de requisições](/api-reference/rate-limits) — esta rota pode responder:

| Código | Status | Descrição |
|--------|--------|-----------|
| `INTERNAL_ERROR` | `500` | Falha interna ao processar a requisição |
