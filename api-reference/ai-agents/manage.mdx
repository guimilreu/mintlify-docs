Agentes de IA qualificam e atendem conversas de forma autônoma. Estes endpoints permitem criar e gerenciar o ciclo de vida dos agentes.

**Escopos:** `read:ai_agents` (leitura), `write:ai_agents` (escrita) — disponível nos planos **Growth e Scale**.

## Listar agentes

```
GET /v1/ai-agents
```

```bash
curl "https://api.socialsell.ai/v1/ai-agents" \
  -H "Authorization: Bearer sk_live_..."
```

### Objeto agente

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID do agente |
| `name` | string | Nome |
| `description` | string\|null | Descrição |
| `type` | string | `sales` ou `support` |
| `status` | string | `draft`, `active`, `paused` |
| `priority` | integer | Prioridade de execução |
| `scope` | object | Canais e objetivos cobertos |
| `triggers` | array | Eventos que ativam o agente |
| `behavior` | object | Modo de ativação e comportamento |
| `humanization` | object | Configuração de humanização (delays, split) |
| `guardrails` | object | Limites e proteções |
| `tools_allowed` | object | Ferramentas habilitadas |
| `limits` | object | Limites de execução |
| `ai_config` | object | Modelo e parâmetros de IA |
| `stats` | object | Estatísticas agregadas |

## Buscar agente

```
GET /v1/ai-agents/:id
```

## Criar agente

```
POST /v1/ai-agents
```

**Escopo:** `write:ai_agents`

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `name` | string | Sim | Nome (3–100 chars) |
| `type` | string | Sim | `sales` ou `support` |
| `scope` | object | Sim | Canais e objetivos cobertos |
| `triggers` | array | Sim | Eventos que ativam o agente |
| `behavior` | object | Sim | Comportamento e modo de ativação |
| `description` | string | Não | Descrição |
| `humanization` | object | Não | Humanização de respostas |
| `guardrails` | object | Não | Limites e proteções |
| `tools_allowed` | object | Não | Ferramentas habilitadas |
| `limits` | object | Não | Limites de execução |
| `ai_config` | object | Não | Modelo e parâmetros |

<Note>
A estrutura de configuração do agente espelha as opções disponíveis no painel em **Agentes de IA**. Recomenda-se criar um agente pelo painel e usar `GET /v1/ai-agents/:id` como referência para o formato dos objetos aninhados.
</Note>

```bash
curl -X POST https://api.socialsell.ai/v1/ai-agents \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Atendente Suporte L1",
    "type": "support",
    "scope": { "channels": ["whatsapp"], "objectives": ["support"] },
    "triggers": [{ "event": "message.received.from_contact" }],
    "behavior": { "activationMode": "always" }
  }'
```

Retorna `HTTP 201`. O agente é criado com `status: draft`.

## Atualizar agente

```
PATCH /v1/ai-agents/:id
```

**Escopo:** `write:ai_agents`

Envie apenas os campos a alterar.

## Excluir agente

```
DELETE /v1/ai-agents/:id
```

**Escopo:** `write:ai_agents` — retorna `HTTP 204`.

## Ciclo de vida

Todos exigem `write:ai_agents`.

| Ação | Endpoint | Efeito |
|------|----------|--------|
| Publicar | `POST /v1/ai-agents/:id/publish` | `draft` → `active` |
| Pausar | `POST /v1/ai-agents/:id/pause` | `active` → `paused` |
| Retomar | `POST /v1/ai-agents/:id/resume` | `paused` → `active` |
| Duplicar | `POST /v1/ai-agents/:id/duplicate` | Cria cópia em `draft` |

```bash
curl -X POST https://api.socialsell.ai/v1/ai-agents/664p1q2r3s4t5u6v7w8x9y0z/publish \
  -H "Authorization: Bearer sk_live_..."
```

## Kill switch global

```
POST /v1/ai-agents/kill-switch
```

**Escopo:** `write:ai_agents`

Pausa **todos** os agentes ativos da organização de uma vez (emergência). Ao desativar, restaura os agentes ao estado anterior.

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `enabled` | boolean | Sim | `true` pausa todos; `false` restaura |
| `reason` | string | Não | Motivo (auditoria) |

```bash
curl -X POST https://api.socialsell.ai/v1/ai-agents/kill-switch \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"enabled": true, "reason": "Manutenção emergencial"}'
```

```json
{
  "data": {
    "kill_switch": {
      "enabled": true,
      "enabled_at": "2026-06-10T16:00:00.000Z",
      "reason": "Manutenção emergencial"
    }
  }
}
```
