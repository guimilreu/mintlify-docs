---
title: "Retomar agente"
description: "Reativa um agente de IA pausado."
---

## Endpoint

```
POST /v1/ai-agents/:id/resume
```

**Escopo necessário:** `write:ai_agents`

Transição: `paused` → `active`.

<Note>
Um agente em `draft` **não** pode ser retomado — ele nunca esteve no ar. A resposta é `422 INVALID_STATUS`. Use [Publicar agente](/api-reference/ai-agents/publish).
</Note>

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/ai-agents/66445c483fa9572a0b2496cb/resume \
  -H "Authorization: Bearer sk_live_..."
```

## Resposta

Retorna `HTTP 200` com o agente em `status: active`.

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Agente não encontrado |
| `INVALID_STATUS` | `422` | O agente está em `draft` — publique em vez de retomar |
