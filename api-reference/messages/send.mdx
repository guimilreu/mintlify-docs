---
title: "Enviar mensagem"
description: "Envia uma mensagem para um contato via WhatsApp ou Messenger, ou para um grupo do WhatsApp."
---

## Endpoint

```
POST /v1/messages/send
```

Também disponível como `POST /v1/conversations/send` (alias).

**Escopo necessário:** `write:messages`

## Destinos suportados

| Destino | Canal | Requisito |
|---------|-------|-----------|
| Contato (`contact_id`) | `whatsapp` | Telefone válido, preferencialmente no formato internacional com DDI, como `+5511999999999` |
| Contato (`contact_id`) | `messenger` | `messenger_psid` preenchido |
| Grupo (`group_id`) | `whatsapp` | Grupo de um número do WhatsApp por QR Code, listado em [Grupos do WhatsApp](/api-reference/lookup/whatsapp-groups) |

Informe `contact_id` ou `group_id`, nunca os dois.

<Note>
O canal Instagram não está disponível na API pública neste momento.
</Note>

<Note>
Você não precisa conhecer nem informar JID ou outro identificador interno do WhatsApp. A SocialSell resolve o destinatário a partir do telefone e também autorrepara contatos antigos no primeiro envio.
</Note>

## Rate limits por canal

Independentes do plano e cumulativos com o limite por minuto da chave:

| Canal | Limite | Código do erro |
|-------|--------|----------------|
| WhatsApp | 30 mensagens/min **por número**, somando contatos e grupos | `WHATSAPP_INSTANCE_RATE_LIMIT` |
| Messenger | 30 mensagens/min **por página** | `MESSENGER_PAGE_RATE_LIMIT` |

## Corpo da requisição

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `contact_id` | string | Condicional | ID do contato destinatário. Obrigatório quando não há `group_id` |
| `group_id` | string | Condicional | ID do grupo do WhatsApp, no lugar de `contact_id`. Só com `channel=whatsapp` |
| `channel` | string | Sim | `whatsapp` ou `messenger` |
| `type` | string | Não | `text` (padrão), `image`, `video`, `audio`, `document` |
| `content` | string | Condicional | Texto da mensagem. Obrigatório quando `type=text`, exceto em envio de modelo (`template_name`) |
| `media_url` | string | Condicional | URL pública da mídia. Obrigatório para tipos não-texto |
| `whatsapp_instance_id` | string | Não | ID da instância WhatsApp. Se omitido, usa a instância conectada disponível. Em grupo, a mensagem sai sempre pelo número do grupo |
| `messenger_page_id` | string | Não | ID local da conexão Messenger. Se omitido, o contato precisa ter vínculo único comprovado; ambiguidade retorna `409 CONNECTION_REQUIRED` |
| `template_name` | string | Não | Nome do modelo aprovado. **Só funciona em número do WhatsApp Oficial** |
| `template_language` | string | Não | Idioma do modelo. Padrão: `pt_BR`. Precisa bater exatamente com o modelo aprovado |
| `template_components` | array | Não | Componentes e variáveis do modelo, no formato da Meta |

## Comportamento de conversa

Se não existir conversa entre o contato e aquele número ou página, uma é criada automaticamente. O mesmo vale para o grupo: a primeira mensagem cria a conversa do grupo no inbox. A resposta sempre traz o `conversation_id`.

A mensagem é gravada na conversa antes de sair e dispara o webhook [`message.sent`](/webhooks/events), com `channel` e, em grupo, `conversation_type: "group"` e `group`.

## Envio para grupo

O grupo vem de [`GET /v1/whatsapp-instances/:id/groups`](/api-reference/lookup/whatsapp-groups). Aceita texto e mídia; modelo não é enviado para grupo.

| Regra | O que acontece |
|-------|----------------|
| Número | A mensagem sai pelo número de que o grupo faz parte. `whatsapp_instance_id` diferente devolve `422 GROUP_INSTANCE_MISMATCH` |
| WhatsApp Oficial | Grupo só em número por QR Code. Em número oficial: `422 GROUP_REQUIRES_QR_NUMBER` |
| Participação | O número precisa estar no grupo e ter permissão para escrever. Se o WhatsApp recusar, a resposta é `422 MESSAGE_SEND_FAILED` com o motivo |

<Warning>
  **Ritmo e risco de bloqueio.** O WhatsApp não publica um limite seguro para números por QR Code. O
  limite da SocialSell é técnico (30 mensagens/min por número, somando contatos e grupos), não uma
  garantia contra bloqueio. Para reduzir o risco: envie só para grupos em que o cliente espera o aviso,
  espalhe os envios na sua fila em vez de rajadas, varie o texto entre grupos, evite links encurtados e
  mantenha o número em uso normal, com conversas que recebem resposta. Denúncias de participantes pesam
  mais do que o volume.
</Warning>

## Escolha do número

| `whatsapp_instance_id` | O que acontece |
|------------------------|----------------|
| Informado | Usa exatamente esse número — **sem verificar se está conectado** |
| Omitido | Escolhe automaticamente um número com status `connected` |

<Note>
Informar um número desconectado não devolve `NO_WHATSAPP_INSTANCE`: a requisição segue e o envio é recusado com `422 MESSAGE_SEND_FAILED`. Omitir o campo é mais seguro quando você não precisa de um número específico.
</Note>

## Idempotência

Esta rota aceita `Idempotency-Key` — repetir depois de um timeout não envia a mensagem duas vezes. A chave fica gravada com a mensagem: a proteção vale mesmo depois das 24 horas do cache e não depende dele.

| Repetição com a mesma chave | Resposta |
|-----------------------------|----------|
| Mensagem já enviada, mesmo conteúdo | `201` com a mesma mensagem |
| Primeira tentativa ainda em envio | `409 IDEMPOTENCY_IN_PROGRESS`, com `Retry-After` |
| Primeira tentativa falhou | `409 IDEMPOTENCY_KEY_FAILED`. Para tentar de novo, use uma chave nova |
| Outro conteúdo | `422 IDEMPOTENCY_KEY_REUSED` |

Ver [Idempotência](/api-reference/idempotency).

## Exemplos

### Texto via WhatsApp

```bash
curl -X POST https://api.socialsell.ai/v1/messages/send \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "contact_id": "664f1a2b3c4d5e6f78901234",
    "channel": "whatsapp",
    "type": "text",
    "content": "Olá! Sua proposta foi aprovada. Podemos agendar uma reunião?"
  }'
```

### Texto para grupo do WhatsApp

```bash
curl -X POST https://api.socialsell.ai/v1/messages/send \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 3f1c9a2e-7b4d-4e8a-9c21-5d6f7a8b9c0d" \
  -d '{
    "group_id": "6650a1b2c3d4e5f678901234",
    "channel": "whatsapp",
    "type": "text",
    "content": "Sua reunião foi marcada para quinta, às 10h."
  }'
```

### Imagem via WhatsApp

```bash
curl -X POST https://api.socialsell.ai/v1/messages/send \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "contact_id": "664f1a2b3c4d5e6f78901234",
    "channel": "whatsapp",
    "type": "image",
    "media_url": "https://meusistema.com/proposta.jpg",
    "content": "Segue a proposta em anexo!"
  }'
```

### Modelo do WhatsApp Oficial

Com `template_name` informado, `content`, `type` e `media_url` não são usados — o texto vem do modelo aprovado.

<Warning>
  Modelo só existe no **WhatsApp Oficial**. Em um número por QR Code a API devolve
  `422 TEMPLATE_REQUIRES_OFFICIAL_NUMBER`. Confirme o canal do número antes: o campo `channel`
  (`official` \| `qrcode`) aparece em [`whatsapp_instances` de um disparo](/api-reference/broadcasts/list).
</Warning>

O modelo precisa estar **aprovado** (`APPROVED`), pertencer àquele número e bater com o `template_language` informado. Caso contrário: `422 TEMPLATE_NOT_FOUND`.

```bash
curl -X POST https://api.socialsell.ai/v1/messages/send \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "contact_id": "664f1a2b3c4d5e6f78901234",
    "channel": "whatsapp",
    "template_name": "boas_vindas",
    "template_language": "pt_BR",
    "template_components": [
      {
        "type": "body",
        "parameters": [
          {"type": "text", "text": "João Silva"}
        ]
      }
    ]
  }'
```

### Texto via Messenger

```bash
curl -X POST https://api.socialsell.ai/v1/messages/send \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "contact_id": "664f1a2b3c4d5e6f78901234",
    "channel": "messenger",
	"messenger_page_id": "665f1a2b3c4d5e6f78901234",
    "type": "text",
    "content": "Olá! Vi seu interesse no nosso produto. Posso ajudar?"
  }'
```

O ID explícito deve ser da mesma organização e corresponder à identidade Messenger do contato. O servidor nunca escolhe “a primeira página” quando o vínculo não é único.

## Respostas

Retorna `HTTP 201`. O corpo tem duas formas, conforme o caminho de envio.

### Texto e mídia

```json
{
  "data": {
    "id": "664d100d2ac9437188591880",
    "conversation_id": "664632f1260b42723a5ed4ed",
    "group_id": null,
    "content": "Olá! Sua proposta foi aprovada.",
    "type": "text",
    "sender": "agent",
    "status": "sent",
    "sent_at": "2026-06-10T16:00:00.000Z"
  },
  "meta": { "request_id": "req_a1b2c3d4e5f6a7b8" }
}
```

### Modelo do WhatsApp Oficial

```json
{
  "data": {
    "id": "664d100d2ac9437188591880",
    "conversation_id": "664632f1260b42723a5ed4ed",
    "content": "Olá, Maria! Seu pedido 4821 foi confirmado.",
    "type": "template",
    "sender": "agent",
    "status": "sent",
    "sent_at": "2026-06-10T16:00:00.000Z",
    "external_id": "wamid.HBgNNTUxMTk5OTk5OTk5ORUCABEYEjhGN0..."
  },
  "meta": { "request_id": "req_a1b2c3d4e5f6a7b8" }
}
```

<Warning>
  **`external_id` só existe na resposta de modelo.** Nos envios de texto e mídia o campo não vem —
  ele é gravado na mensagem, mas não devolvido. Se a sua integração concilia pelo identificador da Meta,
  leia depois em [`GET /v1/conversations/:id/messages`](/api-reference/conversations/messages).
</Warning>

<Note>
No WhatsApp, `group_id` traz o grupo quando o destino é grupo e `null` quando é contato. No Messenger e no envio de modelo o campo não vem.
</Note>

<Note>
No envio de modelo, `type` vem como `template` — valor fora da lista de `type` da requisição — e `content` traz o corpo do modelo com os parâmetros de `template_components` aplicados — o texto que o contato recebeu. Só um modelo sem texto no corpo devolve o rótulo `[Modelo: nome]`.
</Note>

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `MISSING_REQUIRED_FIELD` | `400` | `contact_id` ausente (e sem `group_id`) |
| `CONFLICTING_RECIPIENT` | `400` | `contact_id` e `group_id` juntos |
| `INVALID_ID` | `400` | `group_id` não é um ID válido |
| `INVALID_CHANNEL` | `400` | Canal inválido, ou `group_id` com canal diferente de `whatsapp` |
| `CHANNEL_NOT_SUPPORTED` | `400` | Instagram ainda não suportado |
| `MISSING_CONTENT` | `400` | `content` ausente para mensagem de texto |
| `MISSING_MEDIA_URL` | `400` | `media_url` ausente para mensagens de mídia |
| `CONTACT_NOT_FOUND` | `404` | Contato não encontrado |
| `GROUP_NOT_FOUND` | `404` | Grupo não encontrado nesta organização |
| `IDEMPOTENCY_IN_PROGRESS` | `409` | A primeira tentativa com esta `Idempotency-Key` ainda está em envio |
| `IDEMPOTENCY_KEY_FAILED` | `409` | A tentativa com esta `Idempotency-Key` falhou. Envie com uma chave nova |
| `IDEMPOTENCY_KEY_REUSED` | `422` | A `Idempotency-Key` já foi usada com outro conteúdo |
| `GROUP_INSTANCE_MISMATCH` | `422` | `whatsapp_instance_id` diferente do número do grupo. O corpo traz o `whatsapp_instance_id` do grupo |
| `GROUP_REQUIRES_QR_NUMBER` | `422` | O grupo está em número do WhatsApp Oficial |
| `TEMPLATE_NOT_SUPPORTED_FOR_GROUP` | `422` | `template_name` informado com `group_id` |
| `MESSAGE_SEND_FAILED` | `422` | O WhatsApp recusou o envio (número desconectado, fora do grupo, sem permissão para escrever etc.). A mensagem traz o motivo e fica como `failed` na conversa |
| `WHATSAPP_INVALID_RECIPIENT`, `WHATSAPP_CLOUD_MEDIA_INVALID` e demais `WHATSAPP_CLOUD_*` | `422` | Recusa do WhatsApp Oficial com código próprio. A mensagem traz o motivo |
| `NO_WHATSAPP_JID` | `422` | Código legado devolvido quando o contato não possui telefone utilizável. A mensagem orienta cadastrar um telefone válido com DDI e o corpo traz `reason: "WHATSAPP_PHONE_REQUIRED"` |
| `NO_WHATSAPP_INSTANCE` | `422` | Sem instância WhatsApp conectada |
| `NO_MESSENGER_PSID` | `422` | Contato sem PSID Messenger |
| `NO_MESSENGER_PAGE` | `422` | Sem página Messenger conectada |
| `TEMPLATE_REQUIRES_OFFICIAL_NUMBER` | `422` | `template_name` informado, mas o número é por QR Code. Modelo só existe no WhatsApp Oficial |
| `TEMPLATE_NOT_FOUND` | `422` | Nenhum modelo aprovado com esse nome e idioma neste número |
| `TEMPLATE_PARAMETERS_MISSING` | `422` | O texto do modelo tem variáveis sem valor em `template_components`. `missing` lista quais (`["1", "2"]`). Nada é enviado nem gravado na conversa |
| `TEMPLATE_SEND_ERROR` | `422` | A Meta recusou o envio do modelo. A mensagem traz o motivo |
| `TEMPLATE_NOT_CONFIRMED` | `502` | O WhatsApp Oficial não confirmou o envio. A mensagem fica como `failed` |
| `MESSENGER_SEND_ERROR` | `500` | Erro devolvido pela API do Messenger |
| `WHATSAPP_INSTANCE_RATE_LIMIT` | `429` | 30 msg/min por número atingido |
| `MESSENGER_PAGE_RATE_LIMIT` | `429` | 30 msg/min por página atingido |
