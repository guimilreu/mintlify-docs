---
title: "Atualizar conversa"
description: "Atualiza o responsável ou status de uma conversa."
---

## Endpoint

```
PATCH /v1/conversations/:id
```

**Escopo necessário:** `write:conversations`

Envie `assigned_to` e/ou `status`. Pelo menos um campo é obrigatório.

## Corpo da requisição

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `assigned_to` | string\|null | ID do membro responsável (`null` para desatribuir) |
| `status` | string | `open` para reabrir, `closed` para arquivar |

## Exemplo — Atribuir conversa

```bash
curl -X PATCH https://api.socialsell.ai/v1/conversations/664632f1260b42723a5ed4ed \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"assigned_to": "664a1b2c3d4e5f6789012345"}'
```

## Exemplo — Fechar conversa

```bash
curl -X PATCH https://api.socialsell.ai/v1/conversations/664632f1260b42723a5ed4ed \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"status": "closed"}'
```

<Warning>
  Fechar uma conversa **já fechada** devolve `422 ALREADY_CLOSED`, e reabrir uma já aberta devolve
  `422 ALREADY_OPEN`. Se a sua integração sincroniza estado periodicamente, trate os dois como sucesso —
  o estado desejado já é o atual.
</Warning>

<Note>
Atribuir dispara `conversation.assigned`; fechar dispara `conversation.closed`.
</Note>
## Resposta

Retorna o objeto conversa atualizado.

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `VALIDATION_ERROR` | `400` | Nenhum campo enviado, ou `status` fora de `open`/`closed` |
| `INVALID_ID` | `400` | ID inválido |
| `MEMBER_NOT_FOUND` | `400` | O `assigned_to` informado não é membro desta organização |
| `NOT_FOUND` | `404` | Conversa não encontrada |
| `ALREADY_CLOSED` | `422` | A conversa já está fechada |
| `ALREADY_OPEN` | `422` | A conversa já está aberta |
