---
title: "Buscar funil de venda"
description: "Retorna os dados completos de um funil de venda."
---

## Endpoint

```
GET /v1/pipelines/:id
```

**Escopo necessário:** `read:pipelines`

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/pipelines/664a1b2c3d4e5f6789012345" \
  -H "Authorization: Bearer sk_live_..."
```

Retorna o objeto funil de venda com todas as etapas, incluindo `deals_count` por etapa.

O formato é o mesmo descrito em [Listar funis](/api-reference/pipelines/list), com as estatísticas por etapa incluídas.

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Funil não encontrado |
