title: "Listar funis de venda"
description: "Retorna todos os funis de venda da organização com suas etapas."
---

## Endpoint

```
GET /v1/pipelines
```

**Escopo necessário:** `read:pipelines`

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/pipelines" \
  -H "Authorization: Bearer sk_live_..."
```

## Objeto funil de venda

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID do funil |
| `name` | string | Nome |
| `description` | string\|null | Descrição |
| `is_default` | boolean | Se é o funil padrão |
| `is_active` | boolean | Se está ativo |
| `stages` | array | Lista de etapas ordenadas |
| `total_deals` | integer | Negócios **abertos** no funil |
| `total_value` | number | Soma do valor dos negócios **abertos** |
| `created_at` | string | Criação |
| `updated_at` | string | Última atualização |

## Objeto stage

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID da etapa — use em `stage_id` nos endpoints de deals |
| `name` | string | Nome da etapa |
| `order` | integer | Posição na sequência (0 = primeira) |
| `color` | string | Cor hexadecimal |
| `win_probability` | integer | Probabilidade de fechamento (0–100) |
| `stalling_enabled` | boolean | Se alerta de estagnação está ativo |
| `stalling_days` | integer\|null | Dias sem movimentação para alertar |
| `deals_count` | integer | Negócios **abertos** nesta etapa |
| `deals_value` | number | Soma do valor dos negócios **abertos** nesta etapa |

<Note>
  Todas as métricas — `total_deals`, `total_value` e as por etapa — contam **apenas negócios abertos**
  (`status: "open"`). Ganhos e perdidos ficam de fora. Para totais que incluam fechados, use
  `GET /v1/deals?pipeline_id=...&status=won`.
</Note>

<Note>
  As ações automáticas `after_won` e `after_lost` são **aceitas na escrita** mas não voltam na leitura —
  não há como conferir a configuração atual pela API. Consulte pelo painel.
</Note>

## Erros

Além dos erros comuns a toda a API — [autenticação](/api-reference/authentication), [escopo](/api-reference/scopes) e [limite de requisições](/api-reference/rate-limits) — esta rota pode responder:

| Código | Status | Descrição |
|--------|--------|-----------|
| `INTERNAL_ERROR` | `500` | Falha interna ao processar a requisição |
