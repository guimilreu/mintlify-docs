---
title: "Listar campos personalizados"
description: "Retorna todos os campos personalizados da organização."
---

Campos personalizados estendem contatos, empresas e negócios com dados próprios da sua operação.

## Endpoint

```
GET /v1/custom-fields
```

**Escopo necessário:** `read:custom_fields`

## Parâmetros de query

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `entity` | string | Filtra por entidade: `contact`, `company`, `deal` |

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/custom-fields?entity=contact" \
  -H "Authorization: Bearer sk_live_..."
```

## Exemplo de resposta

```json
{
  "data": [
    {
      "id": "6646c52790822ff5f59c68cb",
      "key": "cpf",
      "label": "CPF",
      "type": "text",
      "entity": "contact",
      "options": null,
      "default_value": null,
      "required": false,
      "is_active": true,
      "created_at": "2026-03-02T10:00:00.000Z",
      "updated_at": "2026-03-02T10:00:00.000Z"
    }
  ],
  "meta": { "total": 1, "has_more": false }
}
```

## Objeto campo personalizado

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID do campo |
| `key` | string | Chave única (imutável após criação) |
| `label` | string | Rótulo de exibição |
| `type` | string | Tipo do campo |
| `entity` | string | Entidade: `contact`, `company` ou `deal` |
| `options` | array \| null | Opções para `select`/`multiselect`. Vem `null`, não `[]`, quando não há opções |
| `default_value` | any | Valor padrão |
| `required` | boolean | Se é obrigatório |
| `is_active` | boolean | Se está ativo |
| `created_at` | string | Criação |
| `updated_at` | string | Última atualização |

<Tip>
Os valores dos campos personalizados são lidos e gravados via o objeto `custom_fields` (chave → valor) em contatos, empresas e negócios.
</Tip>

## Erros

Além dos erros comuns a toda a API — [autenticação](/api-reference/authentication), [escopo](/api-reference/scopes) e [limite de requisições](/api-reference/rate-limits) — esta rota pode responder:

| Código | Status | Descrição |
|--------|--------|-----------|
| `INTERNAL_ERROR` | `500` | Falha interna ao processar a requisição |
