---
title: "Atualizar campo personalizado"
description: "Atualiza rótulo, opções, valor padrão ou status de um campo personalizado."
---

## Endpoint

```
PATCH /v1/custom-fields/:id
```

**Escopo necessário:** `write:custom_fields`

## Corpo da requisição

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `label` | string | Rótulo de exibição |
| `options` | array | Opções para `select`/`multiselect` |
| `default_value` | any | Valor padrão |
| `required` | boolean | Obrigatoriedade |
| `is_active` | boolean | Ativa/desativa o campo |

<Note>
`key`, `type` e `entity` são imutáveis e não podem ser alterados após a criação.
</Note>

## Exemplo de requisição

```bash
curl -X PATCH https://api.socialsell.ai/v1/custom-fields/6646c52790822ff5f59c68cb \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"required": true, "label": "CPF do cliente"}'
```

## Resposta

Retorna `HTTP 200` com o campo atualizado.

<Note>
  **Não existe exclusão de campo personalizado na v1.** Para tirar um campo de circulação, envie
  `is_active: false` — o histórico dos registros que já usam o campo é preservado.
</Note>

<Note>
A `key`, o `type` e a `entity` são imutáveis. Só `label`, `options`, `default_value`, `required` e `is_active` podem mudar.
</Note>

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `VALIDATION_ERROR` | `400` | Corpo inválido, ou nenhum campo enviado |
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Campo não encontrado |
