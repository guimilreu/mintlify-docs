---
title: "Marcar como ganho"
description: "Marca um negócio como ganho (status: won)."
---

## Endpoint

```
POST /v1/deals/:id/won
```

**Escopo necessário:** `write:deals`

## Corpo da requisição

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `value` | number | Não | Atualiza o valor final do negócio |
| `closed_date` | string | Não | Data de fechamento. Padrão: data atual |

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/deals/664c1d2e3f4a5b6789012347/won \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "value": 20000,
    "closed_date": "2026-06-10T00:00:00.000Z"
  }'
```

## Exemplo de resposta

```json
{
  "data": {
    "id": "664c1d2e3f4a5b6789012347",
    "title": "Proposta Enterprise ACME",
    "status": "won",
    "value": 20000,
    "closed_date": "2026-06-10T00:00:00.000Z",
    "updated_at": "2026-06-10T16:00:00.000Z"
  }
}
```

Dispara o evento `deal.won` em webhooks configurados.
