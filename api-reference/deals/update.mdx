---
title: "Atualizar negócio"
description: "Atualiza campos de um negócio existente."
---

## Endpoint

```
PATCH /v1/deals/:id
```

**Escopo necessário:** `write:deals`

Envie apenas os campos que deseja alterar.

## Corpo da requisição

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `contact_ids` | string[] | Substitui todos os contatos vinculados. `[]` remove todos; omitir preserva os vínculos. Os contatos devem pertencer à sua organização |
| `company_id` | string\|null | ID da empresa da sua organização; `null` remove o vínculo |
| `title` | string | Título |
| `description` | string\|null | Descrição |
| `value` | number | Valor em reais |
| `assigned_to` | string\|null | ID do responsável |
| `expected_close_date` | string\|null | Data prevista de fechamento |
| `probability` | integer | Probabilidade 0–100 |
| `tags` | string[] | Substitui completamente as tags |
| `custom_fields` | object | Substitui completamente os campos personalizados |

<Note>
  Campos desconhecidos retornam `422` com código `UNKNOWN_FIELDS` e o nome do campo em `error.details`.
  Para vincular contatos, use `contact_ids`; `contact_id` e `contacts` não são aceitos. Use [Mover](/api-reference/deals/move) para etapa e funil, e
  [Ganho](/api-reference/deals/won) / [Perdido](/api-reference/deals/lost) / [Reabrir](/api-reference/deals/reopen)
  para status.
</Note>

<Note>
Trocar `assigned_to` dispara o webhook `deal.assigned`.
</Note>
## Exemplo de requisição

```bash
curl -X PATCH https://api.socialsell.ai/v1/deals/664c1d2e3f4a5b6789012347 \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "value": 22000,
    "probability": 85,
    "contact_ids": ["664f1a2b3c4d5e6f78901234"],
    "expected_close_date": "2026-07-15T00:00:00.000Z"
  }'
```

## Resposta

Retorna o objeto negócio atualizado.

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Negócio não encontrado |
| `UNKNOWN_FIELDS` | `422` | Campo não aceito neste endpoint; consulte `error.details` |
| `INVALID_REFERENCE` | `422` | Vínculo inválido, inexistente ou de outra organização |
