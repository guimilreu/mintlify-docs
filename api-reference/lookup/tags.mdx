---
title: "Listar tags"
description: "Retorna todas as tags usadas na organização com contagem de uso."
---

## Endpoint

```
GET /v1/tags
```

**Escopo necessário:** `read:tags`

As tags são agregadas de contatos, empresas e negócios, com contagem total de uso em cada entidade.

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/tags" \
  -H "Authorization: Bearer sk_live_..."
```

## Exemplo de resposta

```json
{
  "data": [
    { "name": "lead", "color": "#3B82F6", "count": 128 },
    { "name": "cliente", "color": "#10B981", "count": 87 },
    { "name": "inbound", "color": "#F59E0B", "count": 65 },
    { "name": "vip", "color": "#8B5CF6", "count": 34 },
    { "name": "enterprise", "color": "#EF4444", "count": 12 }
  ],
  "meta": {
    "total": 5,
    "has_more": false
  }
}
```

Os resultados são ordenados por contagem de uso (decrescente).

## Objeto tag

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `name` | string | Nome da tag |
| `color` | string | Cor em hexadecimal, usada no painel |
| `count` | integer | Total de usos (contatos + empresas + negócios) |

## Erros

Além dos erros comuns a toda a API — [autenticação](/api-reference/authentication), [escopo](/api-reference/scopes) e [limite de requisições](/api-reference/rate-limits) — esta rota pode responder:

| Código | Status | Descrição |
|--------|--------|-----------|
| `INTERNAL_ERROR` | `500` | Falha interna ao processar a requisição |
