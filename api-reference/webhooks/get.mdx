---
title: "Buscar webhook"
description: "Retorna os dados de uma assinatura de webhook."
---

## Endpoint

```
GET /v1/webhooks/:id
```

**Escopo necessário:** `read:webhooks`

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/webhooks/664058b720a5c5631521ca8f" \
  -H "Authorization: Bearer sk_live_..."
```

Retorna o objeto webhook (mesmo formato da listagem). O campo `secret` **não** é retornado após a criação.

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Webhook não encontrado |
