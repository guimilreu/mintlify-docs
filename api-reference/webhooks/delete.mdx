---
title: "Excluir webhook"
description: "Remove uma assinatura de webhook."
---

## Endpoint

```
DELETE /v1/webhooks/:id
```

**Escopo necessário:** `write:webhooks`

## Exemplo de requisição

```bash
curl -X DELETE https://api.socialsell.ai/v1/webhooks/664058b720a5c5631521ca8f \
  -H "Authorization: Bearer sk_live_..."
```

## Resposta

Retorna `HTTP 204 No Content`. A assinatura é removida permanentemente e nenhum evento futuro será entregue para a URL configurada.

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Webhook não encontrado |
