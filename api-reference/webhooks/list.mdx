---
title: "Listar webhooks"
description: "Retorna todas as assinaturas de webhook da organização."
---

## Endpoint

```
GET /v1/webhooks
```

**Escopo necessário:** `read:webhooks` — disponível a partir do plano **Growth**

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/webhooks" \
  -H "Authorization: Bearer sk_live_..."
```

## Exemplo de resposta

```json
{
  "data": [
    {
      "id": "664058b720a5c5631521ca8f",
      "name": "Notificações ERP",
      "url": "https://meusistema.com/webhook/socialsell",
      "events": ["deal.won", "deal.stage.changed", "channel.disconnected"],
      "status": "active",
      "last_delivery_at": "2026-06-10T15:50:00.000Z",
      "last_failure_at": null,
      "consecutive_failures": 0,
      "created_at": "2026-05-01T10:00:00.000Z",
      "updated_at": "2026-06-10T15:50:00.000Z"
    }
  ],
  "meta": {
    "total": 2,
    "has_more": false
  }
}
```

## Objeto webhook

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID da assinatura |
| `name` | string | Nome descritivo |
| `url` | string | URL de destino (HTTPS) |
| `events` | string[] | Eventos assinados |
| `status` | string | `active` ou `paused` |
| `last_delivery_at` | string\|null | Última entrega bem-sucedida |
| `last_failure_at` | string\|null | Última falha de entrega |
| `consecutive_failures` | integer | Falhas consecutivas acumuladas |
| `created_at` | string | Timestamp de criação |
| `updated_at` | string | Timestamp de atualização |

## Erros

Além dos erros comuns a toda a API — [autenticação](/api-reference/authentication), [escopo](/api-reference/scopes) e [limite de requisições](/api-reference/rate-limits) — esta rota pode responder:

| Código | Status | Descrição |
|--------|--------|-----------|
| `INTERNAL_ERROR` | `500` | Falha interna ao processar a requisição |
