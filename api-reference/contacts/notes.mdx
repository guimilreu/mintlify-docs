## Listar notas

```
GET /v1/contacts/:id/notes
```

**Escopo necessário:** `read:contacts`

```bash
curl "https://api.socialsell.ai/v1/contacts/664f1a2b3c4d5e6f78901234/notes" \
  -H "Authorization: Bearer sk_live_..."
```

## Criar nota

```
POST /v1/contacts/:id/notes
```

**Escopo necessário:** `write:contacts`

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `content` | string | Sim | Conteúdo da nota. Até **1000 caracteres** |
| `color` | string | Não | Cor: `yellow` (padrão), `blue`, `green`, `pink`, `orange`, `purple`, `red`, `gray` |
| `category` | string | Não | Categoria: `general` (padrão), `follow_up`, `important`, `reminder`, `meeting`, `objection`, `success` |

```bash
curl -X POST https://api.socialsell.ai/v1/contacts/664f1a2b3c4d5e6f78901234/notes \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Reunião agendada para 15/06. Interesse confirmado.",
    "color": "green",
    "category": "meeting"
  }'
```

Retorna `HTTP 201` com a nota criada.

## Atualizar nota

```
PATCH /v1/contacts/:id/notes/:noteId
```

**Escopo necessário:** `write:contacts`

Envie apenas os campos que deseja alterar:

```bash
curl -X PATCH https://api.socialsell.ai/v1/contacts/664f1a2b3c4d5e6f78901234/notes/664167c588160ade00666a77 \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Reunião confirmada para 15/06 às 14h.",
    "category": "important"
  }'
```

## Excluir nota

```
DELETE /v1/contacts/:id/notes/:noteId
```

**Escopo necessário:** `write:contacts`

```bash
curl -X DELETE https://api.socialsell.ai/v1/contacts/664f1a2b3c4d5e6f78901234/notes/664167c588160ade00666a77 \
  -H "Authorization: Bearer sk_live_..."
```

Retorna `HTTP 204 No Content`.

## Objeto nota

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID da nota |
| `content` | string | Conteúdo |
| `color` | string | Cor: `yellow`, `blue`, `green`, `pink`, `orange`, `purple`, `red`, `gray` |
| `category` | string | Categoria: `general`, `follow_up`, `important`, `reminder`, `meeting`, `objection`, `success` |
| `is_pinned` | boolean | Se a nota está fixada |
| `created_by` | object \| null | Quem criou `{id, name}`. Notas criadas via API aparecem como `API (nome da chave)` |
| `created_at` | string | Timestamp de criação |
| `updated_at` | string | Timestamp de atualização |

<Note>
  Valores inválidos em `color` e `category` **não geram erro** — caem no padrão (`yellow` e `general`)
  em silêncio. Confira a grafia se a nota voltar com uma cor que você não pediu.
</Note>

## Autoria

A API Key não representa uma pessoa. A nota criada por aqui é atribuída ao **usuário que criou a chave**, e aparece no painel como `API (nome da chave)`.

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID do contato ou da nota com formato inválido |
| `MISSING_CONTENT` | `400` | Campo `content` ausente |
| `CONTENT_TOO_LONG` | `400` | Nota acima de 1000 caracteres |
| `NOT_FOUND` | `404` | Contato ou nota não encontrada |
