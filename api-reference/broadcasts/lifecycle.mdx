## Estimar audiência

```
POST /v1/broadcasts/audience/estimate
```

**Escopo:** `read:broadcasts`

Calcula quantos contatos serão atingidos por uma configuração de audiência, antes de criar o disparo.

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `audience` | object | Sim | Mesma estrutura do `audience` em criar disparo |

```bash
curl -X POST https://api.socialsell.ai/v1/broadcasts/audience/estimate \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"audience": {"type": "tags", "tags": ["cliente"], "tagsOperator": "or", "hasWhatsapp": true}}'
```

```json
{
  "data": { "estimated_count": 1250, "estimated_exclusions": 0 }
}
```

## Lançar disparo

```
POST /v1/broadcasts/:id/launch
```

**Escopo:** `write:broadcasts`

Inicia o envio. Só funciona para disparos em `draft` ou `scheduled`.

| Campo | Tipo | Obrigatório | Descrição |
|-------|------|-------------|-----------|
| `confirmWarmupOverride` | boolean | Não | Força o envio mesmo acima do limite de warm-up da instância |

```bash
curl -X POST https://api.socialsell.ai/v1/broadcasts/664t3s4t5u6v7w8x9y0z1a2b/launch \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{}'
```

### Erros de lançamento

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_STATUS` | `422` | Disparo não pode ser lançado neste status |
| `MIXED_PROVIDERS` | `400` | Não misture instâncias Evolution e Cloud |
| `MISSING_MESSAGE` | `400` | Escreva a mensagem antes de lançar |
| `MISSING_CLOUD_TEMPLATE` | `400` | Disparos Cloud exigem template HSM aprovado |

<Warning>
Se o volume exceder o limite de warm-up de uma instância, o lançamento é bloqueado. Reenvie com `confirm_warmup_override: true` para forçar.
</Warning>

## Controlar disparo

Todos exigem `write:broadcasts`.

| Ação | Endpoint | Efeito |
|------|----------|--------|
| Pausar | `POST /v1/broadcasts/:id/pause` | Pausa o envio em andamento |
| Retomar | `POST /v1/broadcasts/:id/resume` | Retoma envio pausado |
| Cancelar | `POST /v1/broadcasts/:id/cancel` | Cancela definitivamente |

```bash
curl -X POST https://api.socialsell.ai/v1/broadcasts/664t3s4t5u6v7w8x9y0z1a2b/pause \
  -H "Authorization: Bearer sk_live_..."
```

## Mensagens do disparo

```
GET /v1/broadcasts/:id/messages
```

**Escopo:** `read:broadcasts`

Lista as mensagens individuais enviadas no disparo, com status de entrega por contato.

## KPIs

```
GET /v1/broadcasts/kpis
```

**Escopo:** `read:broadcasts`

Métricas agregadas dos últimos 30 dias.

```bash
curl "https://api.socialsell.ai/v1/broadcasts/kpis" \
  -H "Authorization: Bearer sk_live_..."
```

```json
{
  "data": {
    "broadcasts_this_month": 8,
    "messages_sent": 9400,
    "avg_delivery_rate": 0.95,
    "avg_read_rate": 0.62
  }
}
```

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `broadcasts_this_month` | integer | Disparos criados nos últimos 30 dias |
| `messages_sent` | integer | Total de mensagens enviadas |
| `avg_delivery_rate` | number | Taxa média de entrega (0–1) |
| `avg_read_rate` | number | Taxa média de leitura (0–1) |
