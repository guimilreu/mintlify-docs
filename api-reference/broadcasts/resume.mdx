---
title: "Retomar disparo"
description: "Retoma um disparo pausado, continuando os envios pendentes."
---

## Endpoint

```
POST /v1/broadcasts/:id/resume
```

**Escopo necessário:** `write:broadcasts`

Transição de status: `paused` → `running`

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/broadcasts/664t3s4t5u6v7w8x9y0z1a2b/resume \
  -H "Authorization: Bearer sk_live_..."
```

## Resposta

Retorna `HTTP 200` com o disparo no status `running`.
