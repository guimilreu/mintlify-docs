---
title: "Listar disparos"
description: "Retorna os disparos em massa da organização, com estatísticas atualizadas."
---

## Endpoint

```
GET /v1/broadcasts
```

**Escopo necessário:** `read:broadcasts` — disponível no plano **Growth ou superior**

## Parâmetros de query

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `limit` | integer | Itens por página. Padrão: `25`. Máximo: `100` |
| `cursor` | string | Token de paginação |
| `status` | string | Filtra por status. Use `all` (ou omita) para todos |
| `instance_id` | string | Filtra por número do WhatsApp usado no disparo |
| `search` | string | Busca por nome da campanha, case-insensitive |

## Status possíveis

| Status | Significa |
|--------|-----------|
| `draft` | Rascunho. Nada foi enviado |
| `scheduled` | Agendado para uma data futura |
| `processing` | Lançado; resolvendo a audiência e enfileirando os envios |
| `sending` | Mensagens saindo |
| `paused` | Pausado — manualmente ou pelo disjuntor anti-ban. Ver `pause_reason` e `pause_code` |
| `completed` | Terminou sem falhas relevantes |
| `completed_with_errors` | Terminou, mas parte das mensagens falhou |
| `cancelled` | Cancelado antes de terminar |
| `failed` | Interrompido por erro. Ver `failure_reason` |

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/broadcasts?status=sending&limit=10" \
  -H "Authorization: Bearer sk_live_..."
```

## Objeto disparo

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID do disparo |
| `name` | string | Nome da campanha |
| `description` | string \| null | Descrição |
| `status` | string | Ver tabela de status acima |
| `whatsapp_instances` | array | Números usados. Ver objeto abaixo |
| `cloud_template` | object \| null | Modelo do WhatsApp Oficial, quando houver |
| `audience` | object | Segmentação, no mesmo formato aceito em [Criar disparo](/api-reference/broadcasts/create). As tags voltam como **nomes** |
| `message` | object | Conteúdo da mensagem |
| `send_config` | object | Perfil, janela de envio e agendamento |
| `stats` | object | Métricas. Ver objeto abaixo |
| `started_at` | string \| null | Quando o envio começou |
| `completed_at` | string \| null | Quando terminou |
| `paused_at` | string \| null | Quando foi pausado |
| `pause_reason` | string \| null | Motivo da pausa, legível |
| `pause_code` | string \| null | Código da pausa, para tratamento programático |
| `cancelled_at` | string \| null | Quando foi cancelado |
| `estimated_duration_ms` | integer \| null | Duração estimada do envio |
| `failure_reason` | string \| null | Motivo da falha, quando `status` é `failed` |
| `created_at` | string | Criação |
| `updated_at` | string | Última atualização |

### Objeto número do WhatsApp

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID do número |
| `name` | string \| null | Nome de exibição |
| `phone` | string \| null | Telefone |
| `status` | string | `connected` ou o estado bruto quando desconectado |
| `channel` | string | `official` (WhatsApp Oficial, cobrado por mensagem pela Meta) ou `qrcode` |

### Objeto `cloud_template`

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID do modelo |
| `name` | string \| null | Nome do modelo na Meta |
| `category` | string \| null | Categoria (define o custo da mensagem) |
| `status` | string \| null | Status de aprovação na Meta |
| `language` | string \| null | Idioma usado no disparo |
| `variables_count` | integer | Quantas variáveis estão mapeadas |

### Objeto `stats`

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `totalRecipients` | integer | Destinatários resolvidos |
| `sent` | integer | Mensagens enviadas |
| `delivered` | integer | Entregues |
| `read` | integer | Lidas |
| `failed` | integer | Falhas |
| `skipped` | integer | Puladas pelas regras de exclusão |
| `byProvider` | object | Os mesmos contadores, separados por canal |
| `errorsByType` | object | Falhas agrupadas por código de erro: `{count, label, message}` |

<Note>
  Dentro de `byProvider`, as chaves são `evolution` (números por QR Code) e `cloud` (WhatsApp Oficial).
  O nome `evolution` é legado do provedor original e permanece por compatibilidade — na interface e no
  resto da API o canal se chama **QR Code**.
</Note>

## Erros

Além dos erros comuns a toda a API — [autenticação](/api-reference/authentication), [escopo](/api-reference/scopes) e [limite de requisições](/api-reference/rate-limits) — esta rota pode responder:

| Código | Status | Descrição |
|--------|--------|-----------|
| `INTERNAL_ERROR` | `500` | Falha interna ao processar a requisição |
