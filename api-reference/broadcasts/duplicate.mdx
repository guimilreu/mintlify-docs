---
title: "Duplicar disparo"
description: "Cria uma cópia de um disparo existente em status de rascunho."
---

## Endpoint

```
POST /v1/broadcasts/:id/duplicate
```

**Escopo necessário:** `write:broadcasts`

Cria uma cópia completa do disparo (audiência, mensagem, configuração de envio) com status `draft`.

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/broadcasts/664t3s4t5u6v7w8x9y0z1a2b/duplicate \
  -H "Authorization: Bearer sk_live_..."
```

## Resposta

Retorna `HTTP 201` com o novo disparo em `status: draft`.
