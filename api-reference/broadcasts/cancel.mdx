---
title: "Cancelar disparo"
description: "Cancela um disparo definitivamente. Não há como retomar."
---

## Endpoint

```
POST /v1/broadcasts/:id/cancel
```

**Escopo necessário:** `write:broadcasts`

Transições aceitas: `processing`, `sending` ou `paused` → `cancelled`.

<Warning>
O cancelamento é definitivo — não existe endpoint para retomar um disparo cancelado. Se a intenção é só interromper, use [Pausar](/api-reference/broadcasts/pause).
</Warning>

As mensagens **já enviadas** permanecem: elas chegaram ao contato e continuam no histórico da conversa. O cancelamento só impede o que ainda não saiu.

## Exemplo de requisição

```bash
curl -X POST https://api.socialsell.ai/v1/broadcasts/6648aefe065dd4c1a34780a1/cancel \
  -H "Authorization: Bearer sk_live_..."
```

## Resposta

Retorna `HTTP 200` com uma confirmação enxuta — **não** o objeto disparo completo:

```json
{
  "data": { "id": "6648aefe065dd4c1a34780a1", "status": "cancelled" },
  "meta": { "request_id": "req_a1b2c3d4e5f6a7b8" }
}
```

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Disparo não encontrado |
| `INVALID_STATUS` | `422` | O disparo não está em `processing`, `sending` nem `paused` |
