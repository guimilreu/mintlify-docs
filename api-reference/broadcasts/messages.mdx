---
title: "Mensagens do disparo"
description: "Lista as mensagens individuais de um disparo, com o status de entrega por contato."
---

## Endpoint

```
GET /v1/broadcasts/:id/messages
```

**Escopo necessário:** `read:broadcasts`

Use para auditar entrega contato a contato — quem recebeu, quem falhou e com qual identificador na Meta.

## Parâmetros de query

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `limit` | integer | Itens por página. Padrão: `50`. Máximo: `100` |
| `cursor` | string | Token de paginação. Ordenação fixa: mais recentes primeiro |

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/broadcasts/6648aefe065dd4c1a34780a1/messages?limit=50" \
  -H "Authorization: Bearer sk_live_..."
```

## Objeto mensagem do disparo

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID da mensagem |
| `contact` | object \| null | Destinatário `{id, name, phone}` |
| `content` | string \| null | Texto enviado, já com as variáveis resolvidas |
| `status` | string | `pending` (criada, ainda não enviada), `sent`, `delivered`, `read` ou `failed` |
| `external_id` | string \| null | Identificador da mensagem no WhatsApp. `null` quando o envio falhou antes de sair |
| `sent_at` | string | Quando a mensagem foi criada |

<Tip>
Para o consolidado por motivo de falha, em vez de percorrer esta lista, use `stats.errorsByType` no [objeto disparo](/api-reference/broadcasts/list).
</Tip>

## Erros

| Código | Status | Descrição |
|--------|--------|-----------|
| `INVALID_ID` | `400` | ID com formato inválido |
| `NOT_FOUND` | `404` | Disparo não encontrado |
