---
title: "KPIs de disparos"
description: "Métricas agregadas de todos os disparos dos últimos 30 dias."
---

## Endpoint

```
GET /v1/broadcasts/kpis
```

**Escopo necessário:** `read:broadcasts`

## Exemplo de requisição

```bash
curl "https://api.socialsell.ai/v1/broadcasts/kpis" \
  -H "Authorization: Bearer sk_live_..."
```

## Exemplo de resposta

```json
{
  "data": {
    "broadcasts_this_month": 8,
    "messages_sent": 9400,
    "avg_delivery_rate": 0.95,
    "avg_read_rate": 0.62
  }
}
```

## Campos da resposta

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `broadcasts_this_month` | integer | Disparos criados nos últimos 30 dias |
| `messages_sent` | integer | Total de mensagens enviadas no período |
| `avg_delivery_rate` | number | Taxa média de entrega (0–1) |
| `avg_read_rate` | number | Taxa média de leitura (0–1) |

## Erros

Além dos erros comuns a toda a API — [autenticação](/api-reference/authentication), [escopo](/api-reference/scopes) e [limite de requisições](/api-reference/rate-limits) — esta rota pode responder:

| Código | Status | Descrição |
|--------|--------|-----------|
| `INTERNAL_ERROR` | `500` | Falha interna ao processar a requisição |
