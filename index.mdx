## Bem-vindo à API SocialSell

A API pública v1 da SocialSell permite integrar seu CRM, conversas, negócios e automações com qualquer sistema externo. Use para sincronizar dados, disparar ações e receber eventos em tempo real.

## Base URL

```
https://api.socialsell.ai/v1
```

Todas as requisições devem usar **HTTPS**. O corpo das requisições deve ser `application/json`.

## Exemplo rápido

```bash
curl https://api.socialsell.ai/v1/contacts \
  -H "Authorization: Bearer sk_live_sua_chave_aqui"
```
