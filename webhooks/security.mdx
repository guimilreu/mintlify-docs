title: "Segurança e verificação"
description: "Como validar a assinatura HMAC de cada entrega para garantir que ela veio da SocialSell."
---

Qualquer pessoa que descubra a URL do seu webhook pode simular uma entrega. Por isso a SocialSell assina cada requisição com HMAC-SHA256 usando o `secret` da assinatura — e você **deve** validar antes de processar qualquer payload.

## Os headers de cada entrega

| Header | Exemplo | Para que serve |
| --- | --- | --- |
| `X-Webhook-Signature` | `sha256=a1b2c3…` | A assinatura. É o que você valida. |
| `X-Webhook-Timestamp` | `1755693000` | Epoch em **segundos**. Entra no cálculo da assinatura e permite recusar entregas antigas. |
| `X-Webhook-Event` | `deal.won` | Nome do evento, para rotear sem parsear o corpo. |
| `X-Webhook-Id` | `664f1a2b…` | Qual das suas assinaturas gerou esta entrega. |
| `User-Agent` | `SocialSell-Webhooks/1.0` | Identifica o remetente. |

## O que é assinado

<Warning>
  A assinatura **não** é do corpo sozinho. É do timestamp e do corpo, unidos por um ponto:

  ```
  assinatura = HMAC_SHA256(secret, "{timestamp}.{corpo_bruto}")
  ```

  O valor do header vem prefixado por `sha256=`. Incluir o timestamp é o que permite recusar uma
  entrega capturada e reenviada horas depois.
</Warning>

Use sempre o corpo **bruto** (bytes), nunca o JSON já parseado: reserializar reordena chaves e muda espaçamento, e a assinatura deixa de bater.

## Como validar

<CodeGroup>

```javascript Node.js (Express)
const crypto = require('crypto');
const express = require('express');
const app = express();

const TOLERANCIA_SEGUNDOS = 300; // 5 minutos

// express.raw() entrega o corpo como Buffer, sem parsear
app.post('/webhooks/socialsell', express.raw({ type: 'application/json' }), (req, res) => {
  const assinatura = req.headers['x-webhook-signature'];
  const timestamp = req.headers['x-webhook-timestamp'];
  const secret = process.env.SOCIALSELL_WEBHOOK_SECRET;

  if (!assinaturaValida(req.body, timestamp, assinatura, secret)) {
    return res.status(401).json({ error: 'Assinatura inválida' });
  }

  const evento = JSON.parse(req.body);
  console.log('Evento recebido:', evento.type);

  // Responda rápido e processe depois
  res.status(200).send('OK');
});

function assinaturaValida(corpoBruto, timestamp, assinatura, secret) {
  if (!assinatura || !timestamp) return false;

  // Rejeita entregas fora da janela — protege contra replay
  const idade = Math.abs(Math.floor(Date.now() / 1000) - Number(timestamp));
  if (!Number.isFinite(idade) || idade > TOLERANCIA_SEGUNDOS) return false;

  const esperada = 'sha256=' + crypto
    .createHmac('sha256', secret)
    .update(`${timestamp}.${corpoBruto}`)
    .digest('hex');

  const a = Buffer.from(assinatura);
  const b = Buffer.from(esperada);
  // Comparação em tempo constante: `===` vaza, pelo tempo de resposta,
  // quanto do prefixo estava certo
  return a.length === b.length && crypto.timingSafeEqual(a, b);
}
```

```python Python (Flask)
import hmac
import hashlib
import os
import time
from flask import Flask, request, abort

app = Flask(__name__)
TOLERANCIA_SEGUNDOS = 300

@app.route('/webhooks/socialsell', methods=['POST'])
def webhook():
    assinatura = request.headers.get('X-Webhook-Signature', '')
    timestamp = request.headers.get('X-Webhook-Timestamp', '')
    secret = os.environ['SOCIALSELL_WEBHOOK_SECRET'].encode()

    if not assinatura_valida(request.data, timestamp, assinatura, secret):
        abort(401)

    evento = request.json
    print(f"Evento recebido: {evento['type']}")
    return 'OK', 200


def assinatura_valida(corpo_bruto, timestamp, assinatura, secret):
    if not assinatura or not timestamp:
        return False

    try:
        idade = abs(int(time.time()) - int(timestamp))
    except ValueError:
        return False
    if idade > TOLERANCIA_SEGUNDOS:
        return False

    base = f"{timestamp}.".encode() + corpo_bruto
    esperada = 'sha256=' + hmac.new(secret, base, hashlib.sha256).hexdigest()
    return hmac.compare_digest(assinatura, esperada)
```

```php PHP
<?php
$tolerancia = 300;

$corpoBruto = file_get_contents('php://input');
$assinatura = $_SERVER['HTTP_X_WEBHOOK_SIGNATURE'] ?? '';

    http_response_code(401);

$evento = json_decode($corpoBruto, true);
```

```go Go
package main

import (
	"crypto/hmac"
	"crypto/sha256"
	"encoding/hex"
	"encoding/json"
	"io"
	"net/http"
	"os"
	"strconv"
	"time"
)

const toleranciaSegundos = 300

func handler(w http.ResponseWriter, r *http.Request) {
	corpoBruto, _ := io.ReadAll(r.Body)
	assinatura := r.Header.Get("X-Webhook-Signature")
	timestamp := r.Header.Get("X-Webhook-Timestamp")
	secret := os.Getenv("SOCIALSELL_WEBHOOK_SECRET")

	ts, err := strconv.ParseInt(timestamp, 10, 64)
	if err != nil || abs(time.Now().Unix()-ts) > toleranciaSegundos {
		http.Error(w, "Assinatura inválida", http.StatusUnauthorized)
		return
	}

	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write([]byte(timestamp + "."))
	mac.Write(corpoBruto)
	esperada := "sha256=" + hex.EncodeToString(mac.Sum(nil))

	if !hmac.Equal([]byte(esperada), []byte(assinatura)) {
		http.Error(w, "Assinatura inválida", http.StatusUnauthorized)
		return
	}

	var evento struct {
		Type string `json:"type"`
	}
	json.Unmarshal(corpoBruto, &evento)

	w.WriteHeader(http.StatusOK)
	w.Write([]byte("OK"))
}

func abs(n int64) int64 {
	if n < 0 {
		return -n
	}
	return n
}
```

## Testando sua validação

Chame `POST /v1/webhooks/{id}/test` (ou o botão **Testar** no painel) para receber uma entrega real assinada com o seu secret. O evento chega com `type: "webhook.test"` e é entregue **na hora**, sem retentativa — a resposta da chamada traz o status HTTP e o tempo do seu endpoint.

<Note>
`webhook.test` **não é um evento assinável** — ele não aparece na [referência de eventos](/webhooks/events) e não precisa (nem pode) ser incluído em `events` ao criar a assinatura. Ele chega apenas quando você aciona o teste. Trate-o como um caso à parte no seu roteador de eventos.
</Note>

```bash
curl -X POST https://api.socialsell.ai/v1/webhooks/664f1a2b3c4d5e6f78901234/test \
  -H "Authorization: Bearer sk_live_..."
```

<Note>
  O teste só funciona em assinatura **ativa**. Endpoint pausado devolve `409 WEBHOOK_PAUSED` — um teste
  verde num webhook pausado seria o resultado mais enganoso possível.
</Note>

## Erros comuns de validação

| Sintoma | Causa | Correção |
| --- | --- | --- |
| Assinatura nunca bate | Assinando só o corpo | A base é `` `${timestamp}.${corpo}` ``, com o ponto |
| Assinatura nunca bate | Corpo parseado antes de validar | Use os bytes brutos (`express.raw`, `request.data`, `php://input`) |
| Assinatura nunca bate | Comparando sem o prefixo | O header inclui `sha256=` |
| `timingSafeEqual` lança | Strings de tamanhos diferentes | Compare o tamanho antes; costuma ser secret errado |
| Funciona local, falha em produção | Proxy reescrevendo o corpo | Configure o proxy para repassar o corpo intacto |
| Passou a falhar de repente | Secret rotacionado | Atualize a variável de ambiente com o novo secret |

## Rotação de secret

Se o secret vazou, gere um novo sem recriar a assinatura nem perder o histórico:

```bash
curl -X POST https://api.socialsell.ai/v1/webhooks/664f1a2b3c4d5e6f78901234/rotate-secret \
  -H "Authorization: Bearer sk_live_..."
```

<Warning>
  A rotação vale **na hora**: a próxima entrega já vai assinada com o secret novo. Atualize o seu
  backend antes de rotacionar, ou aceite uma janela curta de entregas rejeitadas — elas serão
  reentregues pelo mecanismo de retentativa.
</Warning>

## Como o secret é guardado

Do nosso lado, o `secret` fica **cifrado em repouso** (AES-256-GCM) e nunca é devolvido por nenhum endpoint de leitura — só na criação e na rotação. Nem a listagem nem o detalhe da assinatura trazem o valor.

Do seu lado, trate-o como credencial: variável de ambiente, fora do repositório, e rotacione se houver qualquer suspeita.

## Boas práticas

- **Valide antes de processar.** Nunca confie no payload sem conferir a assinatura.
- **Use comparação em tempo constante.** `hmac.compare_digest`, `crypto.timingSafeEqual`, `hash_equals`, `hmac.Equal`.
- **Rejeite entregas velhas.** Uma janela de 5 minutos sobre o `X-Webhook-Timestamp` mata replay.
- **Responda `401`, não `200`.** Responder sucesso a payload inválido confunde seu próprio monitoramento.
- **Guarde o secret como variável de ambiente.** Nunca no código nem no repositório.
- **A URL precisa ser HTTPS pública.** Endereços de rede privada, `localhost` e faixas reservadas são recusados no cadastro e novamente no momento da entrega. Redirects não são seguidos.
